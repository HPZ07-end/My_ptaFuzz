# MOS3 fixture provenance

These fixtures are small, executable adaptations of official ngspice material.
They use only the project's current `.op`/`.tran` control cards and fixed DC
sources, so the future MOS3 implementation can be assessed without adding
unrelated PWL, `.control`, `.ic`, or `.include` support.  Model cards and MOS
instance geometry are retained verbatim unless noted below.

The upstream source was cloned from the official SourceForge repository:

The local reference generator uses `/opt/homebrew/bin/ngspice`, which reports
`ngspice-46`.  Each committed reference is generated by that executable from
the fixture in this directory.  MOS3 transient references use `TSTEP / 20` as
ngspice's temporary maximum internal step; the short UIC fixture otherwise
causes unnecessarily tiny adaptive startup steps. Regenerate with `make
generate-mos3-standards`.

| Fixture | Official origin | Adaptation |
| --- | --- | --- |
| `op/mos3_01_cmosedu_nmos_bias.cir` | `examples/xspice/see/CMOSComparator/cmosedu_models.txt`, model `N_1u` | Retains the entire NMOS Level-3 card; adds a four-terminal DC bias circuit, physical diffusion geometry, multiplier, and a 0-V current-sense source. |
| `op/mos3_02_cmosedu_pmos_bias.cir` | same file, model `P_1u` | Retains the entire PMOS Level-3 card; adds the complementary DC bias and current-sense circuit. |
| `op/mos3_03_mos6_process_model_op.cir` | `tests/mos6/mos6inv.cir`, models `N10L3` and `P12L3` | Retains the process-derived Level-3 cards (notably no explicit `KP`); reduces the upstream PWL-driven inverter to one deterministic DC operating point. |
| `op/mos3_04_bug481_series_geometry_op.cir` | [ngspice bug #481](https://sourceforge.net/p/ngspice/bugs/481/) | Retains the published PMOS model and `AD/AS/PD/PS/NRD/NRS/M` instance values; replaces the ticket's PWL source and `.ic` setup with a DC load so it fits the project's current analysis subset. |
| `tran/mos3_05_cmosedu_charge_uic.cir` | `examples/xspice/see/CMOSComparator/cmosedu_models.txt`, model `P_1u` | Retains the published PMOS Level-3 card; adds a UIC charge-up transient to exercise overlap, Meyer, and drain-bulk charge without requiring PWL support. |

The origin files are distributed by the ngspice project under its repository
licence.  This suite retains only the portions required for focused regression;
the links and revision above make the upstream context reproducible.
